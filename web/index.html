GET STARTED / 使用说明

从一个任务开始。

先把要做的事写清楚，再积累可以检查的工作记录。

01

留下任务简报

填写目标、不能违反的约束和已定方案。它们由你维护，不会自动从聊天记录中猜测生成。

02

记录一次验证

用 CLI 显式运行检查命令，保留退出状态、输出和项目内容快照。失败与过期会分别显示。

gravity-companion check <task-id> -- node --test

此示例要求已安装 CLI，并在目标工作区执行。也可以直接复制工作台为当前任务生成的完整命令，再把 node --test 换成项目实际使用的检查程序。

03

审阅后交接

预览 Markdown 或 JSON，检查内容和敏感信息，再交给 Codex、Claude Code 或新的反重力会话。导入的验证声明不会自动变成本机证据。

04

接入官方 hooks

按项目文档安装原生插件，或合并工作区 hooks 配置。只有接入后产生的事件才会显示在会话动态中。

面板不读取账号凭证，不修改客户端安装包，也不改变官方配额与权限策略。

目前的边界

本项目是独立社区工具。没有接入聊天正文、官方额度池和宿主测试结果；不会承诺零封号或无限额度。会话安静时只显示待检查提示，hooks 事件不能证明测试通过。

交接内容和命令输出可能包含你主动写入的信息，分享前请复核。服务仅绑定本机地址，关闭终端中的服务即可停止面板。

Gravity Companion工作记录留在本机，分享由你决定。
