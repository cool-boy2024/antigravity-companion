# 发布验证记录

版本：0.1.1。核实日期：2026-11-26。

本记录区分自动化测试、官方加载器校验与真实宿主接入。测试通过不代表所有平台和账号均已兼容。

## 自动化验证

使用 Node.js 22.23.5 内置测试器检查本地存储、导入边界、快照变化、并发写入、HTTP 访问控制、显式命令执行以及 `demo` 演示工作区预置与清理。本机 macOS 的 37 项测试全部通过，JS/JSON 与版本号一致性检查通过。

## 官方格式校验

本机官方 Antigravity CLI 1.5.13 的 `agy plugin validate --strict . --json` 已识别 1 个 hook 定义及 1 个 skill，未报告错误或警告。发布 ZIP 通过同一加载器检查。`agy plugin install .` 成功安装到本机官方插件目录，加载列表识别出 hook 和 skill，运行文件完整性另行检查。命名 hook 保持默认关闭。

真实浏览器已确认浅色/深色工作台渲染、任务创建与保存、真实本地检查验收徽章、Claude Code 目标交接预览、竞品观察页与主要布局，并确认地址栏令牌已即时清除且未出现在页面内容中。没有把自动化浏览器看到的界面当作宿主 hook 已触发的证据。

## 需要按环境确认的部分

本地 HTTP 与 CLI 测试通过真实进程、真实文件和真实 HTTP 请求验证。hook 协议通过 stdin 样例验证，并检查不保存 prompt、参数和错误正文。没有用真实 Google 会话触发一次完整的模型任务，因此不声称已完成 Antigravity App、CLI、所有 IDE 的端到端验证。

首次接入时，在指定工作区运行 `init`，安装插件，检查运行文件完整性，再启用命名 hook。创建无敏感信息的测试会话，确认动态页出现对应事件。没有事件时保留“未接入”判断，不把缺失事件解释成模型停滞。

跨平台 CI 检查 Node.js 22 在 Linux、macOS 和 Windows 上的行为。其结果以 GitHub Actions 当前运行记录为准；本地校验本身不构成 Windows 或 Linux 实测。
